# 植物形态指标：定义、单位与资格

版本 `root-morphology-v001`。默认 Z 竖直、负向向下；可选 X/Y/Z、正/负。长度L为唯一最终图边弧长之和。所有长度、面积、体积按用户尺度的1/2/3次幂换算；未标定使用模型单位。角度用degree，比例与维数无量纲，密度用长度的负幂。

## 原实体形状

| 参数 | 定义 | 单位 |
|---|---|---|
| root_depth | 原材料沿竖直轴的最大值减最小值 | 长度 |
| horizontal_spread | 原材料水平投影凸包的最远两点距离 | 长度 |
| width_depth_ratio | 最大水平展幅／深度 | 无量纲 |
| convex_hull_volume | 原材料完整边界的三维凸包体积（包含根间空隙） | 长度³ |
| volume_solidity | 原材料体积／凸包体积 | 无量纲 |
| projected_area | 原占据立方体水平投影并集面积 | 长度² |
| projected_hull_area | 原材料水平投影凸包面积 | 长度² |
| projected_solidity | 水平材料投影面积／水平凸包面积 | 无量纲 |
| surface_volume_ratio | 原实体边界面积／体积，包括空腔边界 | 长度⁻¹ |
| sphericity | π^(1/3)(6V)^(2/3)／S，即等体积球面积／原边界面积 | 无量纲 |

原生实体精确按原占据立方体与暴露面计算V、S。凸包利用 `conv(所有相同立方体)=conv(其格点位置)+单位立方体`，先按0/1/2/3维秩找格点凸包极点，再扩展角点；无需8倍全部单元顶点。不使用抖动或修改输入来避免凸包失败；失败保留状态。水平展幅是平面最远距离，可能大于X或Y包围盒单边宽度。

网格可计算原顶点凸包与展幅；未认证三角材料并集体积和投影并集时，相应体积比、投影充实度、球形度留空。不会用中心线管道体积替代。

## 中心线形态

| 参数 | 定义 | 单位／适用范围 |
|---|---|---|
| hull_length_density | L／原材料凸包体积 | 长度⁻²；完整轴可用时输出；不是土芯根长密度 |
| branching_density | 图中度数≥3节点个数／L | 长度⁻¹；相邻图分叉节点未合并为生物分叉 |
| tortuosity_mean | 最大度2路径的“弧长／端点弦长”，按路径弧长加权 | 排除闭环、零弦长；保留纳入弧长比例和每条路径详情 |
| inclination_mean | acos(abs(边的竖直分量)／边长)，按唯一边弧长加权 | 0°竖直、90°水平；无父子关系，不能解释为侧根萌生角 |
| axis_depth_d50 / d95 | 从实体最上边界沿向下方向，累计包含50%／95%唯一轴长的深度 | 长度；按线段的连续深度分布积分，不按节点数量分位 |
| fractal_dimension_3d | 下述固定尺度三维盒计数斜率 | 有限尺度描述，不认证渐近分形性质 |

深度分布另导出10个等深区间：每层轴长、占完整已提取弧长比例、原材料体积。立方体跨层时按其实际重叠厚度分配，非竖直线段按区间重叠的弧长分配。越出材料深度界限的轴长另列，不塞入边界层。无轴时材料体积剖面仍可用，轴长分位留空。深度零点是最上材料边界，真实土表位置未知；倾斜放置模型必须设置正确竖直方向。

中心线部分/端点未解决时，轴描述标记 `PARTIAL_AXIS_DESCRIPTOR` 或相应部分轴状态；完整凸包内根长密度为空。原实体形状仍可独立计算。任何这些几何数值均不自动构成独立精度或生物学验收。

## 三维盒计数的固定规则

1. 对全部连续唯一图线段及孤立图点计数，不能只数节点（节点疏密会改变后者）。盒为半开区间，网格边界点按floor归属。平移锚点是图包围盒最小值。
2. 分辨率h取原生实体格距，网格取测量报告明确声明的目标格距。只取 `ε=h×2^k ≤ 最大轴包围盒跨度/4`，并要求至少4级（≥8倍跨度）。没有输入分辨率或不足范围，维数为空。不会沿更细尺度外推。
3. 每级使用三轴各0或半盒的8种相位，求各相位盒数N，再拟合 `log(mean N)` 对 `log(最大轴跨度/ε)` 的最小二乘斜率。全部合格尺度固定使用，不搜索最高R²区间。完整JSON保留各级边长、8个盒数、各相位斜率、尺度跨度及R²。
4. R²低于0.98仅显示线性较弱状态；即使高于阈值仍只是有限尺度估计。旋转、网格相位、有限范围、离散分辨率与轴提取会影响结果；比较样本应固定这些约定，并核对各自实际尺度范围。
5. 每相位最多200万估算线段穿盒事件；超过预算返回不可用，保留已算尺度，不以截断曲线拟合出维数。避免构造稠密三维体素数组。

有限折线的渐近盒维数为1，具有正体积的实体在无限细尺度趋于3；本工具描述可观测尺度内根系中心线的空间占据复杂度。它与把体积或二维投影直接代入盒计数不是同一指标。

## 数据与导出

- 新测量：参数JSON含 `morphology`，参数CSV含17项新指标；批量汇总增加主要指标、单位、方向及各项状态。
- 已有测量：`root-measurer morphology ... --output <未使用前缀>` 校验原输入/测量哈希，新增完整JSON、指标CSV、深度CSV；不改写原文件。
- 结果页可切换方向并下载当前设置的三种形态文件；原“参数CSV”保留测量时设置，两者在页面有提示。重新加载恢复测量时设置。
- JSON记录原输入绑定、测量SHA、方法版本、设置、完整尺度与路径详情。独立形态CSV与深度CSV逐行携带方法版本、测量SHA、方向；深度CSV明确材料体积单位。CSV状态为机器可读资格码；空值表示不可用，不能解释为0。

未输出生物根序、主/侧根身份、真实根尖数、侧根萌生角、干重、生物量或比根长；需要额外的根基、父子关系或质量数据。

## 方法背景与核验

三维根系表型常涵盖大小、形状、空间分布与探索范围；这些类别可参照 [Topp et al., PNAS 2013](https://pub.ista.ac.at/~edels/Papers/2013-06-3DPhenotypes.pdf)。本工具具体采用上表约定，不声称所有参数与该论文实现完全相同。

三维与二维投影的分形指标不能直接当成同一个量；[Nielsen, Lynch & Weiss, American Journal of Botany 1997](https://pubmed.ncbi.nlm.nih.gov/11539495/) 对模拟豆根进行了相关比较。本工具明确只提供上述三维中心线有限尺度估计。

自动检查包含：单/线/平面/体分布立方体凸包与全部原始角点凸包对照；长方体尺寸/投影/球形度解析公式；线段深度分布解析积分、毫米幂次、缺轴/部分轴/闭环；直线穿盒精确计数、加密/平移/缩放不变性、对角网格跨越一致性；有限Sierpinski几何趋势控制（与log3/log2比较），以及真实实体端到端测量与增量分析的源哈希保持检查。这些证明实现遵守几何约定，不替代新生物样本上的表型精度验证。
