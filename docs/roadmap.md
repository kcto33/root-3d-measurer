# 独立工具迭代路线

## 0.1.0：独立运行基线

- 可安装wheel、公共Python API/CLI、本地工作台、原生实体批量、可追溯导出。
- 保持既有数值规则、严格单分支/整连通口径分离、失败/阻塞状态保留。
- 生成式小型示例、单元/安装/端到端检查，CI持续执行。

## 0.2.0：形态指标

- 完成17项形态描述、有限尺度三维盒计数、方向设置、深度分布、结果页与导出。
- 已有测量可校验源哈希后增量计算，保留原中心线/长度/半径与失败项。
- 指标定义与独立几何控制见 `morphology.md`；研究批次上的生物学效度仍需单独验收。

## 下一迭代

1. 统一页面用语和运行身份，给每次结果显示运行编号/时间/评分状态，便于区分同名模型的多次运行。
2. 持久化批量任务历史及下载入口，重启后恢复已完成汇总展示。
3. 将完整输出的接触资格审计做成独立命令；逐位置保留分歧，不用候选半径混入主参数。
4. 在新的正确原生实体固定批次上验证，扩展细根、密集分叉、尺度与内存压力情况。
5. 处理全规模PLY分辨率/相位阻塞，再单独验收原面半径及交互；未通过前不扩大兼容声明。
6. 按模块分离输入、图/轴、截面、参数、评分和服务层，逐步移除内部顶层模块兼容；先做边界适配，避免全面重写算法。

每个任务按问题/复现输入/预期行为/验收证据追踪。功能验收与精度验收分别记录。
