# 验证基线与验收口径

本工具从根系三维测量研究原型提取；数值核心保留来源清单和源文件哈希，便携运行层有独立测试。历史结论不自动升级为新提交的验收证书。

历史冻结原生批次（2026-10-29）含8个未按模型调试的有限立方体实体，覆盖斜直根、曲根、渐细、Y分叉、多分叉、真环及密集根系。8/8通过预先固定的独立门槛：总长误差≤3%、逐路径≤5%、参考轴覆盖≥95%、参考半径覆盖/输出有效率/参考可评分弧长≥90%、半径误差≤5%、拓扑和端点匹配通过。观测总长误差0.30%–1.13%，整连通截面半径误差0.11%–0.51%。这批原始数据和实验产物不随独立仓库上传。

全部12,023输出截面的同平面独立检查保留21个点接触资格差异。它们没有被记为零误差。三份相关模型的可配对输出弧长为99.780%、99.757%、99.784%。现场查询新增源实体接触资格检查；资格检查与审计共享GEOS实现，不能把二者的资格一致性当作两套独立算法证明。半径面积内核仍为原生实现。

32个非预存连续位置查询和98项回归检查通过。独立仓库另外验证安装包、可写工作区、合成示例完整测量及查询、批量和HTTP界面。合成示例是安装/功能回归，不标作新的未见模型精度验收。

## 分母与含义

- `V_radius_out`：旧单分支口径有效样本代表的输出弧长/全部输出唯一边长。
- `connected_V_radius_out`：整连通截面口径的对应输出有效率。
- `C_axis_ref`、`C_radius_ref`：正确对应且满足资格条件的参考弧长/完整参考弧长；不是输出站点比例。
- 同平面半径误差只检查面积计算；端到端半径误差同时包含输出轴位置和切向差异。
- 几何端点有估计不等于物理根尖已识别，完整长度可用也不等于独立精度通过。

参见[已知限制](known_limitations.md)。今后每个数值修改都需要固定输入、完整分母、修复前后结果和新的独立批次证据。
